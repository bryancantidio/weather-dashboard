🌤️ Weather Dashboard

Uma aplicação simples de clima que permite buscar qualquer cidade e visualizar informações meteorológicas em tempo real usando a WeatherAPI.

🚀 Funcionalidades
Busca de clima por nome da cidade
Temperatura em tempo real
Sensação térmica
Umidade do ar e velocidade do vento
Histórico de buscas (sessionStorage)
Estatísticas:
Total de consultas
Média de temperaturas
Cidade mais quente pesquisada
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript (Vanilla)
Fetch API
WeatherAPI
