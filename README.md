# 🌤️ Weather Dashboard

Uma aplicação de clima que permite buscar qualquer cidade e visualizar informações meteorológicas em tempo real utilizando a **WeatherAPI**.

---

## 🚀 Funcionalidades

- 🔎 Busca de clima por nome da cidade  
- 🌡️ Temperatura em tempo real  
- 🤔 Sensação térmica  
- 💧 Umidade do ar  
- 🌬️ Velocidade do vento  
- 📊 Histórico de buscas (sessionStorage)  
- 📈 Estatísticas automáticas:
  - Total de consultas  
  - Média de temperaturas  
  - Cidade mais quente pesquisada  

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- Fetch API  
- WeatherAPI
